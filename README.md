# 🌤️ Weather App

A Flask-based weather application that provides real-time weather information for cities around the world.

## ✨ Features

- 🌍 Search weather for cities worldwide
- 📍 Detect current location
- 🌡️ Current temperature
- 💧 Humidity information
- 💨 Wind speed
- 🌦️ Weather condition and icons
- 📅 7-day weather forecast
- 🎨 Background changes according to weather conditions
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Open-Meteo API
- JavaScript

## 🌐 API

Weather data is provided by the **Open-Meteo API**.
